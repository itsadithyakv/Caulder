# Caulder branding

Made by `python scripts/branding.py` from `assets/caulderLogo.png`. Change
the logo there and run it again; don't edit these by hand.

| Folder | What | Where it goes |
| --- | --- | --- |
| `mark/` | The mark alone, transparent. `-for-dark` has the ink lifted for dark backgrounds | Anywhere |
| `icon/` | The app icon, 16 to 1024, and `caulder.ico` | Shortcuts, websites, favicons |
| `lockup/` | The mark and the name side by side | Website, documents, slides |
| `store/store-logo-300x300.png` | 1:1 app tile icon | Partner Center › Store listing › Store logos |
| `store/store-logo-150x150.png`, `-71x71.png` | Square 150 and 71 logos | The same section |
| `store/*-paper.png` | The same three on the app's paper colour | Where a solid background is wanted |
| `store/box-art-*` | 1:1 box art (1080 or 2160) | Store logos |
| `store/poster-art-*` | 9:16 poster art (720×1080 or 1440×2160) | Store logos |
| `store/hero-art-*` | 16:9 hero art, no words (the Store adds the name) | Store display images |
| `social/` | Link preview 1200×630; GitHub social preview 1280×640 | Repository settings, link cards |

Colours: ink `#1f1914`, flame `#fb8300`, paper `#f8f5ee`. The name is set in
Gilroy Bold, in capitals.
